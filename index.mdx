Zend is a money network for the internet. Everyone on it has an @name, money moves between them in seconds with no fees, and anyone can build apps on top.

Every app built on Zend shares the same network:

- **People.** Sign in with Zend gives you a real person with an @name and one ID that's the same in every app. You don't build a sign-up screen.
- **Money.** Payments, ask links, money links, splits and prizes, priced in Naira. Zend draws every money screen, so you never build or secure a payment UI.
- **Reach.** Your app shows up in the chats and Activity feed people already use, and its links open anywhere a URL does.

## What you don't have to build

| You'd normally build | On Zend |
|---|---|
| Sign-up, login, profiles | `zend.identity.get()` |
| Payment screens and their security | Zend's confirm sheet |
| A friend list and invite flow | Zend's people picker and chat actions |
| A realtime server | [Live rooms](/guides/live-rooms) |
| Notifications that bring people back | Cards in chats and the Activity feed |

All HTTP paths in these docs are under `https://api.usezend.app`.
