title: "Quickstart"
description: "Create a ZApp, deploy its manifest, and open it inside Zend."
---

You'll build a page that greets the signed-in Zend user, then open it inside Zend.

## Prerequisites

- A Zend account with the Zend app on your phone.
- Node.js 18 or later.
- An HTTPS origin you control for your page. Any static host works (Cloudflare Pages, Vercel, Netlify). The origin can't be on `usezend.app`.

<Steps>
  <Step title="Install the CLI and log in">
    ```bash
    npm install -g pay-with-zend-cli
    zend login
    ```

    The CLI prints a link and a QR code. Open it on your phone, tap **Approve** in Zend, and the CLI saves its key to `~/.zend/config.json`. See [Log in](/cli/login).
  </Step>

  <Step title="Create the app">
    ```bash
    zend apps create hello "Hello"
    ```

    The CLI prints `ZEND_APP_KEY` and `ZEND_WEBHOOK_SECRET` once. Put them in your server's secret store now; you can't see them again. If you lose them, run [`zend apps rotate-key`](/cli/apps#rotate-key).
  </Step>

  <Step title="Write the manifest">
    Save this as `zapp.json`, with your own origin:

    ```json zapp.json
    {
      "app": "hello",
      "name": "Hello",
      "version": "0.1.0",
      "origins": ["https://hello.example.com"],
      "entry": "/",
      "permissions": []
    }
    ```

    `app` must match the slug you created. Every field is described in [Manifest](/guides/manifest).
  </Step>

  <Step title="Deploy the manifest">
    ```bash
    zend apps deploy zapp.json
    ```

    ```text
    Deployed hello v1
      id:     6b0f…
      status: active
      open:   https://app.usezend.app/apps/hello
    ```

    Private apps go live as soon as the manifest uploads. Nobody reviews them, and Zend labels them "Made by {you}. Not checked by Zend."
  </Step>

  <Step title="Build the page">
    <CodeGroup>
    ```bash npm
    npm install @zendfi/appkit
    ```
    ```bash pnpm
    pnpm add @zendfi/appkit
    ```
    </CodeGroup>

    ```ts main.ts
    import { init, ZendError } from "@zendfi/appkit";

    const zend = init();

    if (zend.environment === "external") {
      // Plain browser: Zend calls reject with NOT_IN_ZEND.
      document.body.innerHTML = `<a href="https://app.usezend.app/apps/hello">Open in Zend</a>`;
    } else {
      try {
        const me = await zend.identity.get();
        document.body.textContent = `Hi ${me.name}!`;
      } catch (e) {
        if (e instanceof ZendError) console.error(e.code, e.message);
      }
    }
    ```

    Deploy the built page to the origin in your manifest.
  </Step>

  <Step title="Open it in Zend">
    Visit `https://app.usezend.app/apps/hello`, or share that link to your phone. The first time, Zend asks "Continue to Hello as {you}?". After you continue, your page shows your name.

    To let a friend try it before you go public, add them as a tester:

    ```bash
    zend apps testers add hello danny
    ```
  </Step>
</Steps>

<Tip>
Want a QR code for your phone, or to point Zend at your laptop? See [Test on your phone](/test-on-your-phone). Building with an AI assistant? [Connect it to these docs](/build-with-ai) first.
</Tip>
